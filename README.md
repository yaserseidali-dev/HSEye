# 🏭 HSEeye.ir - فروشگاه تخصصی آموزشی، ایمنی، بهداشت و محیط‌زیست

## 📌 توضیح پروژه

HSEeye.ir یک پلتفرم جامع برای آموزش و فروش محصولات HSE است که شامل:

- 📚 **بخش آموزشی**: آموزش‌های تخصصی HSE
- 📋 **فرم‌ها و چک‌لیست‌ها**: فرم‌های استاندارد HSE
- 🛍️ **فروشگاه**: فروش فایل‌های آموزشی
- ❓ **آزمون‌های آنلاین**: تست دانش
- 📊 **داشبورد مدیریتی**: برای کسب‌وکار‌ها

1. ✅ ارائه محتوای حرفه‌ای و استاندارد

## 🚀 چگونه شروع کنیم

### 1️⃣ Clone Repository
```bash
git clone https://github.com/yaserseidali-dev/hseye.git
cd hseye
```

### 2️⃣ باز کردن در مرورگر
```bash
# روش 1: مستقیم فایل index.html رو باز کنید
open index.html

# روش 2: استفاده از Live Server
python -m http.server 8000
# سپس به آدرس http://localhost:8000 برید
```

### 3️⃣ ویرایش محتوا
- فایل `index.html` را برای HTML ویرایش کنید
- فایل `css/style.css` را برای طراحی ویرایش کنید
- فایل `js/script.js` را برای عملکرد ویرایش کنید
